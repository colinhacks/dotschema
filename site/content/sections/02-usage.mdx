## Usage

A schema file's default import is its validator, compiled by [ajv](https://ajv.js.org) when the module is built. Nothing on it throws.

### `.validate()`

The `.validate()` method returns the value, or every issue, each with its message, its path and the keyword that failed:

```ts twoslash title="main.ts"
declare const input: unknown;
// ---cut---
import user from "./user.schema.jsonc";

const result = user.validate(input);
if (result.issues) {
  console.log(result.issues);
  // for { name: "" }:
  // [{
  //   message: "must NOT have fewer than 1 characters",
  //   path: ["name"],
  //   keyword: "minLength",
  // }]
} else {
  result.value;
  //     ^?
}
```

### Defaults

A property's `default` is filled in where the value leaves it out:

```jsonc title="settings.schema.jsonc"
{
  "type": "object",
  "properties": {
    "theme": {
      "enum": ["light", "dark"],
      "default": "light"
    }
  },
  "additionalProperties": false
}
```

```ts twoslash title="main.ts"
import settings from "./settings.schema.jsonc";

settings.validate({});
// { value: { theme: "light" } }
```

A default its own schema refuses is a type error:

```jsonc title="settings.schema.jsonc" errors
{
  "type": "object",
  "properties": {
    "theme": {
      "enum": ["light", "dark"],
      "default": "blue"
    }
  }
}
```

### Transforms

The `transform` keyword changes a string before it's checked:

```jsonc title="handle.schema.jsonc"
{
  "type": "string",
  "pattern": "^[a-z_]+$",
  "transform": ["trim", "toLowerCase"]
}
```

```ts twoslash title="main.ts"
import handle from "./handle.schema.jsonc";

handle.validate("  Ada_L ");
// { value: "ada_l" }
```

The transforms are `trim`, `trimStart`, `trimEnd`, `toLowerCase`, `toUpperCase` and `toEnumCase`, which gives an `enum`'s own spelling:

```jsonc title="role.schema.jsonc"
{
  "enum": ["Admin", "Member"],
  "transform": ["toEnumCase"]
}
```

```ts twoslash title="main.ts"
import role from "./role.schema.jsonc";

role.validate("admin");
// { value: "Admin" }
```

### Unlisted keys

A key the schema doesn't list is dropped from the value:

```jsonc title="visitor.schema.jsonc"
{
  "type": "object",
  "properties": {
    "name": { "type": "string" }
  }
}
```

```ts twoslash title="main.ts"
import visitor from "./visitor.schema.jsonc";

visitor.validate({ name: "Ada", admin: true });
// { value: { name: "Ada" } }
```

An object whose `additionalProperties` says what its other keys may be keeps them:

```jsonc title="labels.schema.jsonc"
{
  "type": "object",
  "properties": {
    "name": { "type": "string" }
  },
  "additionalProperties": { "type": "string" }
}
```

```ts twoslash title="main.ts"
import labels from "./labels.schema.jsonc";

labels.validate({ name: "Ada", team: "core" });
// { value: { name: "Ada", team: "core" } }
```

### Copies

The value given is never changed, since `.validate()` copies what it fills in, transforms or drops:

```ts twoslash title="main.ts"
import visitor from "./visitor.schema.jsonc";

const input = { name: "Ada", admin: true };
visitor.validate(input);
// { value: { name: "Ada" } }
input;
// { name: "Ada", admin: true }
```

Where nothing changes, the value is the one given:

```ts twoslash title="main.ts"
import visitor from "./visitor.schema.jsonc";

const input = { name: "Ada" };
visitor.validate(input);
// { value: input }, the same object
```

### `.is()`

The `.is()` method is a type guard, which stops at the first failure:

```ts twoslash title="main.ts"
declare const input: unknown;
// ---cut---
import user from "./user.schema.jsonc";

if (user.is(input)) {
  input;
//^?
}
```

### `.output`

The `.output` type is the value `.validate()` returns:

```ts twoslash title="main.ts"
declare const input: unknown;
// ---cut---
import user from "./user.schema.jsonc";

const result = user.validate(input);
if (!result.issues) {
  const person: user.output = result.value;
}
```

### `.input`

The `.input` type is the value the schema accepts, which may leave out a property with a default:

```ts twoslash title="main.ts"
// @errors: 2741
import settings from "./settings.schema.jsonc";

const saved: settings.input = {};
const loaded: settings.output = {};
```

The `.is()` method narrows to it, since the value it checks is left as it was:

```ts twoslash title="main.ts"
declare const input: unknown;
// ---cut---
import settings from "./settings.schema.jsonc";

if (settings.is(input)) {
  input;
//^?
}
```

### `.pick()`

The `.pick()` method gives the schema with only the properties named:

```ts twoslash title="main.ts"
import user from "./user.schema.jsonc";

const named = user.pick("name");
named.validate({ name: "Ada", role: "admin" });
// { issues: [{
//   message: "must NOT have additional properties",
//   path: ["role"],
//   keyword: "additionalProperties",
// }] }
```

### `.omit()`

The `.omit()` method gives the schema without the properties named:

```ts twoslash title="main.ts"
declare const input: unknown;
// ---cut---
import user from "./user.schema.jsonc";

const anonymous = user.omit("name");
if (anonymous.is(input)) {
  input;
//^?
}
```

### `.partial()`

The `.partial()` method makes the properties named optional, or every property when none is named:

```ts twoslash title="main.ts"
import user from "./user.schema.jsonc";

user.partial().validate({});
// { value: {} }
```

### `.required()`

The `.required()` method makes the properties named required, or every property when none is named:

```ts twoslash title="main.ts"
import user from "./user.schema.jsonc";

user.required("role").validate({ name: "Ada" });
// { issues: [{
//   message: "must have required property 'role'",
//   path: ["role"],
//   keyword: "required",
// }] }
```

### `.keyof()`

The `.keyof()` method gives a schema of the property names:

```ts twoslash title="main.ts"
declare const input: unknown;
// ---cut---
import user from "./user.schema.jsonc";

if (user.keyof().is(input)) {
  input;
//^?
}
```

A schema that is more than an object of properties, such as a `oneOf`, has none of these methods.

### `$defs`

Each entry of `$defs` is a validator of its own, imported by its key:

```jsonc title="place.schema.jsonc"
{
  "type": "object",
  "properties": { "home": { "$ref": "#/$defs/address" } },
  "$defs": {
    "address": {
      "type": "object",
      "properties": { "city": { "type": "string" } },
      "required": ["city"],
      "additionalProperties": false
    }
  }
}
```

```ts twoslash title="main.ts"
declare const input: unknown;
// ---cut---
import { address } from "./place.schema.jsonc";

if (address.is(input)) {
  input;
//^?
}
```

### `~standard`

The module is a [Standard Schema](https://standardschema.dev), so a library that accepts one accepts it:

```ts twoslash title="main.ts"
declare const input: unknown;
// ---cut---
import user from "./user.schema.jsonc";

// the same function as user.validate
user["~standard"].validate(input);
```

It's a Standard JSON Schema too, which gives the schema as one document in draft-07 or 2020-12, with every file it refers to folded in:

```ts twoslash title="main.ts"
import team from "./team.schema.jsonc";

team["~standard"].jsonSchema.input({
  target: "draft-2020-12",
});
// {
//   $schema:
//     "https://json-schema.org/draft/2020-12/schema",
//   type: "object",
//   properties: {
//     members: {
//       type: "array",
//       items: { $ref: "#/$defs/user" },
//     },
//   },
//   required: ["members"],
//   additionalProperties: false,
//   $defs: {
//     user: { type: "object", properties: { ... }, ... },
//   },
// }
```
