## Inference

Each schema file's type is written from its schema at the type check, as the type of the value `.validate()` gives.

### Objects

An object's `properties` are its keys, optional unless `required` lists them:

<Inferred>

```jsonc title="profile.schema.jsonc"
{
  "type": "object",
  "properties": {
    "name": { "type": "string" },
    "age": { "type": "integer" }
  },
  "required": ["name"],
  "additionalProperties": false
}
```

</Inferred>

The type is `.output` on the import:

```ts twoslash title="main.ts"
// @errors: 2322
import profile from "./profile.schema.jsonc";

const ada: profile.output = { name: "Ada", age: 36 };
const bob: profile.output = { name: "Bob", age: "old" };
```

A `readOnly` property is `readonly`:

<Inferred>

```jsonc title="article.schema.jsonc"
{
  "type": "object",
  "properties": {
    "id": { "type": "string", "readOnly": true },
    "title": { "type": "string" }
  },
  "required": ["id", "title"],
  "additionalProperties": false
}
```

</Inferred>

### Null

A list of types is a union, `null` among them:

<Inferred>

```jsonc title="contact.schema.jsonc"
{
  "type": "object",
  "properties": {
    "phone": { "type": ["string", "null"] }
  },
  "required": ["phone"],
  "additionalProperties": false
}
```

</Inferred>

### Literals

An `enum` or a `const` is a literal type:

<Inferred>

```jsonc title="post.schema.jsonc"
{
  "type": "object",
  "properties": {
    "status": { "enum": ["draft", "published"] },
    "version": { "const": 1 }
  },
  "required": ["status", "version"],
  "additionalProperties": false
}
```

</Inferred>

### Records

A schema in `additionalProperties` types every other key:

<Inferred>

```jsonc title="scores.schema.jsonc"
{
  "type": "object",
  "additionalProperties": { "type": "number" }
}
```

</Inferred>

A schema in `patternProperties` types the keys it matches:

<Inferred>

```jsonc title="headers.schema.jsonc"
{
  "type": "object",
  "patternProperties": {
    "^x-": { "type": "string" }
  },
  "additionalProperties": false
}
```

</Inferred>

### Arrays

A schema in `items` types every item:

<Inferred>

```jsonc title="tags.schema.jsonc"
{
  "type": "array",
  "items": { "type": "string" },
  "uniqueItems": true
}
```

</Inferred>

### Tuples

A `prefixItems` list is a tuple, each item required up to `minItems`:

<Inferred>

```jsonc title="point.schema.jsonc"
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "array",
  "prefixItems": [
    { "type": "number" },
    { "type": "number" }
  ],
  "minItems": 2,
  "items": false
}
```

</Inferred>

A schema in `items` beside it types the rest:

<Inferred>

```jsonc title="row.schema.jsonc"
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "array",
  "prefixItems": [{ "type": "string" }],
  "minItems": 1,
  "items": { "type": "boolean" }
}
```

</Inferred>

### Unions

An `anyOf` or a `oneOf` is a union:

<Inferred>

```jsonc title="id.schema.jsonc"
{
  "anyOf": [
    { "type": "string" },
    { "type": "integer" }
  ]
}
```

</Inferred>

A `oneOf` whose variants a `const` tells apart is a discriminated union:

<Inferred>

```jsonc title="event.schema.jsonc"
{
  "oneOf": [
    {
      "type": "object",
      "properties": {
        "kind": { "const": "click" },
        "x": { "type": "number" }
      },
      "required": ["kind", "x"],
      "additionalProperties": false
    },
    {
      "type": "object",
      "properties": {
        "kind": { "const": "visit" },
        "url": { "type": "string" }
      },
      "required": ["kind", "url"],
      "additionalProperties": false
    }
  ]
}
```

</Inferred>

### Intersections

An `allOf` is an intersection:

<Inferred>

```jsonc title="staff.schema.jsonc"
{
  "allOf": [
    {
      "type": "object",
      "properties": { "name": { "type": "string" } },
      "required": ["name"]
    },
    {
      "type": "object",
      "properties": { "team": { "type": "string" } },
      "required": ["team"]
    }
  ]
}
```

</Inferred>

With `unevaluatedProperties: false` beside it, the intersection allows no other key:

<Inferred>

```jsonc title="manager.schema.jsonc"
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "allOf": [
    {
      "type": "object",
      "properties": { "name": { "type": "string" } },
      "required": ["name"]
    }
  ],
  "properties": { "reports": { "type": "integer" } },
  "unevaluatedProperties": false
}
```

</Inferred>

### Conditionals

An `if` that tests a `const` makes `then` and `else` a union:

<Inferred>

```jsonc title="payment.schema.jsonc"
{
  "type": "object",
  "properties": { "method": { "enum": ["card", "bank"] } },
  "required": ["method"],
  "if": {
    "properties": { "method": { "const": "card" } }
  },
  "then": {
    "properties": { "card": { "type": "string" } },
    "required": ["card"]
  },
  "else": {
    "properties": { "iban": { "type": "string" } },
    "required": ["iban"]
  }
}
```

</Inferred>

### Recursion

A `$ref` back into its own file is a type that refers to itself:

<Inferred>

```jsonc title="tree.schema.jsonc"
{
  "type": "object",
  "properties": {
    "name": { "type": "string" },
    "children": {
      "type": "array",
      "items": { "$ref": "#" }
    }
  },
  "required": ["name"],
  "additionalProperties": false
}
```

</Inferred>

Two schemas of one file that refer to each other are two types that do:

<Inferred>

```jsonc title="person.schema.jsonc"
{
  "type": "object",
  "properties": {
    "name": { "type": "string" },
    "pets": {
      "type": "array",
      "items": { "$ref": "#/$defs/pet" }
    }
  },
  "required": ["name"],
  "additionalProperties": false,
  "$defs": {
    "pet": {
      "type": "object",
      "properties": {
        "name": { "type": "string" },
        "owner": { "$ref": "#" }
      },
      "required": ["name"],
      "additionalProperties": false
    }
  }
}
```

</Inferred>

### References

A `$ref` can point to another schema file, by a path relative to this one:

```jsonc tab="team.schema.jsonc"
{
  "type": "object",
  "properties": {
    "members": {
      "type": "array",
      "items": { "$ref": "./user.schema.jsonc" }
    }
  },
  "required": ["members"],
  "additionalProperties": false
}
```

```jsonc tab="user.schema.jsonc"
{
  "type": "object",
  "properties": {
    "name": { "type": "string", "minLength": 1 },
    "role": { "enum": ["admin", "member"] }
  },
  "required": ["name"],
  "additionalProperties": false
}
```

The type imports the other file's, by its name:

```ts twoslash title="main.ts"
import team from "./team.schema.jsonc";

type Members = team.output["members"];
//   ^?
```

A `$ref` with a fragment points into the other file, to a definition or an anchor:

```jsonc
{ "$ref": "./place.schema.jsonc#/$defs/address" }
```

### Never

A `false` schema allows no value, and neither does `{ "not": {} }`, so the type of each is `never`:

<Inferred>

```jsonc title="signup.schema.jsonc"
{
  "type": "object",
  "properties": {
    "email": { "type": "string" },
    "password": false,
    "admin": { "not": {} }
  },
  "required": ["email"]
}
```

</Inferred>

### Checks

A keyword no TypeScript type can express leaves the type as it is, and the validator checks it:

<Inferred>

```jsonc title="email.schema.jsonc"
{
  "type": "string",
  "format": "email",
  "maxLength": 254
}
```

</Inferred>

### Formats

Zod's string formats are checked as Zod checks them, `jwt` among them:

```jsonc title="session.schema.jsonc"
{
  "type": "object",
  "properties": {
    "token": { "type": "string", "format": "jwt" }
  }
}
```

```ts twoslash title="main.ts"
import session from "./session.schema.jsonc";

session.validate({ token: "not a token" });
// { issues: [{
//   message: "must match format \"jwt\"",
//   path: ["token"],
//   keyword: "format",
// }] }
```

### Unrecognized keywords

A keyword the schema's draft doesn't define is ignored, by the type and by the validator, so a schema written for another validator still compiles:

```jsonc title="account.schema.jsonc"
{
  "type": "object",
  "properties": {
    "id": {
      "type": "string",
      "x-internal": true,
      "tsType": "AccountId"
    }
  },
  "required": ["id"],
  "additionalProperties": false
}
```

```ts twoslash title="main.ts"
import account from "./account.schema.jsonc";

type Id = account.output["id"];
//   ^?
```
