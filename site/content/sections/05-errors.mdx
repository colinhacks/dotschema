## Errors

An invalid schema is a type error, at its place in the file:

```jsonc title="team.schema.jsonc" errors
{
  "type": "object",
  "properties": {
    "members": {
      "type": "array",
      "items": { "$ref": "./member.schema.jsonc" }
    }
  },
  "required": ["members"]
}
```

The type check prints it with its line and column:

```ansi title="Terminal"
$ tsc --noEmit --runExternalCode
[96mteam.schema.jsonc[0m:[93m6[0m:[93m27[0m - [91merror[0m[90m dotschema4: [0mThe $ref "./member.schema.jsonc" names a file that does not exist.

[90m6[0m       "items": { "$ref": "./member.schema.jsonc" }
[90m [0m [91m                          ~~~~~~~~~~~~~~~~~~~~~[0m


Found 1 error in team.schema.jsonc[90m:6[0m
```

The `errorMessage` keyword, [ajv-errors'](https://ajv.js.org/packages/ajv-errors.html), gives an issue a message of the schema's own:

```jsonc title="signup.schema.jsonc"
{
  "type": "object",
  "properties": {
    "age": {
      "type": "integer",
      "minimum": 13,
      "errorMessage": "must be 13 or older"
    }
  }
}
```

The issue keeps its path and the keyword that failed:

```ts twoslash title="main.ts"
import signup from "./signup.schema.jsonc";

signup.validate({ age: 9 });
// { issues: [{
//   message: "must be 13 or older",
//   path: ["age"],
//   keyword: "minimum",
// }] }
```
