<p className="dk-subheader">Import JSON Schemas into TypeScript. Fully typed, scary fast.</p>

If you have a JSON Schema like this:

```jsonc title="user.schema.jsonc"
{
  "type": "object",
  "properties": {
    "name": { "type": "string", "minLength": 1 },
    "role": { "enum": ["admin", "member"] }
  },
  "required": ["name"],
  "additionalProperties": false
}
```

You can import it directly from a TypeScript file, and get its type and a validator:

```ts twoslash title="main.ts"
// @hover: user data
declare const request: Request;
// ---cut---
import user from "./user.schema.jsonc";

const data = await request.json();

if (user.is(data)) {
  data; // hover over data to see its type
}
```

It's powered by TypeScript's [_content mappers_](https://github.com/microsoft/typescript-go/pull/4712) (introduced in TypeScript 7.1), which let a package give `tsc` the types of a file it imports. The validator is dotschema's own, which compiles each schema to JavaScript the first time it runs.
